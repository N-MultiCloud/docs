Hardware-focused documentation: BIOS settings, default-config files, sample
configs, serial-console connectivity, SFP-compatibility tables, quickstart
for OPNsense appliances.

| File / Path | Topic |
|---|---|
| `bios.rst` | BIOS recommendations. |
| `configs/` | Sample / reference config snippets. |
| `defaults.rst` | Default configuration values. |
| `files/` | Static reference files. |
| `images/` | Hardware screenshots. |
| `quickstart.rst` | Quickstart for new appliances. |
| `serial_connectivity.rst` | Serial console guidance. |
| `sfp_compatibility.rst` | SFP module compatibility matrix. |
| `support.rst` | Hardware support overview. |

## Working Rules

- Read-only vendor source.
- The SFP-compatibility matrix and BIOS recommendations are operationally
  useful when modeling appliances in NetBox (see
  [`../../../../netbox/`](../../../../netbox/) for that side).
